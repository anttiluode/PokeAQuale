The purpose of this ledger is to prevent the philosophical vocabulary from outrunning the executable result.

Every gate below is a finite / synthetic mechanism test. None is evidence that the tested system is conscious or that the operational object is identical to phenomenal experience.

## The hypothesis after eleven attacks

The executable story has become:

```text
active intervention
 -> predictive / causal identity
 -> cheap learned shortcuts while stable
 -> re-grounding when shortcuts break
 -> discover variables controlling future affordances
 -> compress them into transferable causal bottlenecks
 -> optimize them only relative to an explicit objective
```

The strongest computational claim presently earned is:

> **A bounded agent can use intervention-conditioned futures to discover transferable causal sufficient statistics for its future action/sensing possibilities, while cheaper passive representations can predict those statistics when the environment remains stable. Those variables can acquire instrumental value under an objective.**

The stopping lines are now equally important:

```text
causal role -> future affordance
                   !=
                 valence
```

> **Causal structure gives consequence; an objective gives value.**

Nothing so far requires privileged SELF vocabulary, an intrinsic inside/outside boundary, a canonical good/bad ordering, or phenomenology.

## Gate 11 result — preserving options is not intrinsically good

The world is fixed. At the first step the agent can choose:

```text
PRESERVE
  -> capacity 1
  -> 3 future actions

COLLAPSE
  -> capacity 0
  -> 1 future action
  -> large immediate task cashout
```

No transition, capacity, or affordance relation changes between evaluations. Only the objective changes.

The policies split exactly as they should if value is extra structure:

```text
empowerment       -> PRESERVE
viability         -> PRESERVE
task reward       -> COLLAPSE
reversed viability-> COLLAPSE
```

Negating the viability utility flips the preferred action while leaving the world untouched. A generic planner reproduces every one of these policies once supplied the corresponding objective.

So the dynamics can tell us which action preserves the observer's future options. They cannot, by themselves, tell us that preserving those options is good.

The narrow result earned is:

> **Future-affordance variables can become instrumentally valuable under objectives that depend on continued control, but their causal role alone does not define a canonical valence.**

That places a hard fence between self-maintaining control and subjective valence.

## Gate 12 preregistration — can the objective be recovered from behavior?

The obvious escape is to say: perhaps the organism need not be *given* a value function; perhaps its behavior reveals the intrinsic objective.

That move has its own identification problem.

Gate 12 should construct one finite decision process and multiple reward functions that induce exactly the same optimal policy / demonstrations. Compare:

```text
1. behavior-only inverse-reward inference
2. reward-shaping / policy-equivalent alternatives
3. intervention or preference-query evidence
4. oracle reward
```

Mandatory attackers and stopping lines:

- if multiple reward functions produce the same complete demonstrated policy, behavior alone must not identify a unique `true value`;
- adding a potential-based / policy-preserving reward transformation must leave behavior unchanged while changing numerical reward assignments;
- preference queries may reduce the equivalence class only by adding new evidence;
- if two reward functions remain behaviorally and interventionally equivalent under every available query, the repo must stop at an equivalence class rather than invent a hidden valence;
- no reward variable is to be called felt valence.

The narrow result worth earning is:

> **An observer may infer constraints on an agent's objective from choices, but objective identity itself can remain non-identifiable under policy-equivalent reward transformations.**

If that survives, PokeAQuale will have reached a fairly clean boundary: intervention can identify causal structure, but neither semantic origin nor value origin is free.

## Current philosophical boundary

The repo can investigate agent-relative distinguishability, causal anchoring, transferable causal state, self-maintaining control, and objective-relative planning. It cannot infer that any of these structures feel like anything.

G6 commits the project to this answer:

> If every available action-conditioned relation is preserved by an automorphism, no extra hidden semantic fact can be recovered operationally.

G10 adds:

> If a generic causal abstraction with no SELF vocabulary discovers the same sufficient statistic at the same model size, the computational result belongs to causal representation learning / system identification, not to a privileged ontology of self.

G11 adds:

> Fixed causal dynamics can support opposite preferences under different objectives. Therefore preserving the observer's future options is not, by causal structure alone, a canonical good.

These are not temporary missing features. They are part of the current theory's definition.
